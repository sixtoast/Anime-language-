# Grammar and Linguistic Structure

Use this folder for organized grammar documentation as the language specification develops.

Potential areas include phonology and phonotactics, orthography, morphology, lexical categories, syntax, semantics, pragmatics, word formation, and example paradigms.

## Active recovery work

- [Arcane Grammar Recovery Matrix](./GRAMMAR-RECOVERY-MATRIX.md) — source-backed status and next acceptance gate for surface syntax, aliases, lexicon, operators, dimensions, bindings, control blocks, numerals, registers, and feasibility.

## Canonical-status rule

Do not treat a proposal, reconstruction, or audit hypothesis as canonical merely because it is documented here. Clearly label each item as canonical, historical, provisional, or unresolved, and link it to its source evidence and decision record where possible.

Keep changes to the authoritative specification traceable and reviewable.
