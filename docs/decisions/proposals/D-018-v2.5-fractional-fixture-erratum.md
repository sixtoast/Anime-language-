# D-018 proposal — Modern Vernacular v2.5 fractional-fixture erratum

**Status:** Proposed editorial correction; not accepted and not part of locked canon  
**Date:** 2026-11-07  
**Scope:** One inconsistent acceptance/rejection fixture only

## Observation

Modern Vernacular v2.5 §3 states that a fractional part contains one to three digit tokens. The NUM25-14 row in §7 currently gives:

`teshi don zir rawu to shi sa fi re se`

and labels it “more than three fractional digits”. The fractional part in that input is `sa fi re`, exactly three digit tokens. It therefore conflicts with the explicit one-to-three-token rule.

## Proposed correction

Change only the NUM25-14 example to:

`teshi don zir rawu to shi sa fi re du se`

This contains four fractional digit tokens and correctly exercises the stated rejection boundary.

No grammar, digit value, precision limit, duration meaning, tolerance, unit conversion or other semantic rule is changed. The implementation and regression test follow the explicit §3 rule: one to three fractional digit tokens are accepted; four are rejected.

## Current handling

The canonical source file has not been changed by this proposal. The implementation test uses the four-digit form above so it does not encode a test expectation that contradicts §3. The source inconsistency remains visible pending owner review.
