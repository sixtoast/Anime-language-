# Arcane Phase 9B — core verb-frame teaching paradigms and role-reversal tests

**Status:** Learner-facing design prototype; not canon

## 1. Purpose

Phase 9A consolidated the proposed starter vocabulary and simple clause pilot. This phase takes the next practical step: it gives the learner and reviewer a compact set of semantic paradigms for core verbs and identifies exactly what the current SVO pilot can and cannot communicate.

The source lexicon records these verbs as Vernacular / PROPOSED, with English glosses. It does not establish their argument frames. Accordingly, the paradigms below are **meaning-and-role exercises**, not claims that all meanings can already be expressed by the same Arcane surface construction.

## 2. Notation

- **A, B, C:** participants in a neutral semantic scenario.
- **X, Y:** entities or themes.
- **E:** event; **P:** proposition/content.
- **GIVER, RECIPIENT, THEME**, etc.: analysis labels in English, not Arcane morphemes.
- **SVO pilot string:** a constructed example using the provisional subject–verb–object pattern from Phase 7E/9A.
- **UNRESOLVED:** no safe Arcane surface string can be given with current evidence.

## 3. SEE — `wish`

### Meaning-and-role contrast

| Case | Intended scenario | What the grammar must preserve |
|---|---|---|
| WSH-01 | A sees B | A is perceiver; B is perceived theme |
| WSH-02 | B sees A | Roles reverse; B is perceiver |
| WSH-03 | A sees event E | Event perception vs entity perception |
| WSH-04 | A sees object X but infers event E | Direct perception vs inference |
| WSH-05 | A tries to see B but cannot perceive B | Attempt vs successful perception |

### SVO pilot illustration

- `teshi wish fezo` — intended “The person sees the friend.”
- Reversal target: “The friend sees the person.” **UNRESOLVED** as a distinct surface string without approved role marking and a demonstrated noun/verb frame.

The pilot can suggest an order, but one pair of examples does not prove that roles are reliably recoverable in every context. If both participant nouns can occupy both roles, the grammar must provide a stable way to distinguish them.

## 4. SAY — `zir`

### Meaning-and-role contrast

| Case | Intended scenario | What the grammar must preserve |
|---|---|---|
| ZIR-01 | A says message M | Speaker vs message |
| ZIR-02 | A says message M to B | Addressee distinct from message |
| ZIR-03 | A says the exact words “B came” | Direct quotation |
| ZIR-04 | A says that B came | Reported proposition |
| ZIR-05 | A does not say P / A says not-P | Matrix vs embedded negation; surface forms unresolved |

### SVO pilot illustration

A simple string such as `teshi zir rawu` could be guessed to mean “The person says a word”, but this remains a **constructed hypothesis**, not a validated frame: the lexicon does not establish whether `zir` takes a message noun directly, requires quotation/content marking, or allows an addressee.

Therefore the learner grammar should not yet use `zir` to teach reported speech or quotations as if their boundaries were settled.

## 5. GO and COME — `ful` and `zem`

| Case | Intended scenario | Required distinction |
|---|---|---|
| MOT-01 | A is at L | Static location |
| MOT-02 | A goes to L | Goal |
| MOT-03 | A goes from L | Source |
| MOT-04 | A moves along path P | Path |
| MOT-05 | A approaches L but does not enter | Approach vs arrival/boundary crossing |
| MOT-06 | A comes toward the speaker | Deictic centre |
| MOT-07 | A comes toward B, who is not the speaker | Non-speaker centre |
| MOT-08 | A reaches L | Arrival/completion vs movement direction |

### Surface-language boundary

The proposed preposition `desh` is glossed “in/at”. Its draft gloss does not license goal (“to”), source (“from”), or path. Formal spatial relations such as JO/JUR/JA cannot automatically be inserted into vernacular clauses.

A candidate such as `teshi ful gezi` might be interpreted by a learner as “The person goes home”, but the available sources do not establish whether the location noun is a goal complement, a static location, or whether an adposition is required. It remains a hypothesis, not a recommended canonical sentence.

## 6. CAN — `fam`

| Case | Intended scenario | Required distinction |
|---|---|---|
| FAM-01 | A has the skill to lift X | Ability |
| FAM-02 | A is permitted to lift X | Permission |
| FAM-03 | Conditions make lifting X physically possible | Event possibility |
| FAM-04 | A can lift X but does not lift X | Modality does not entail actual action |
| FAM-05 | A cannot lift X because of a physical limit | Inability |
| FAM-06 | A must not lift X | Prohibition, not inability |

The source gloss “can” underdetermines the modal meaning. Until an approved contract distinguishes ability, permission and possibility, avoid teaching `fam` as if it were interchangeable with all English uses of “can”.

## 7. GIVE and TAKE — `bul` and `lil`

| Case | Intended scenario | Required distinction |
|---|---|---|
| TRF-01 | A gives X to B | Giver, theme and recipient |
| TRF-02 | A gives X for C's benefit | Beneficiary distinct from recipient |
| TRF-03 | A gives X to B for C's benefit | Recipient and beneficiary co-occur |
| TRF-04 | A attempts to give X to B, but transfer fails | Attempt vs completed transfer |
| TRF-05 | A takes X from B | Taker, theme and source |
| TRF-06 | B takes X from A | Role reversal |
| TRF-07 | A takes X without a stated source | Source omission policy |
| TRF-08 | A gives X to B, but B never receives it | Transfer verb vs successful receipt |

The proposed adposition `push` (“for”) does not automatically distinguish a recipient from a beneficiary. Do not use it as “to” without a documented extension or an approved separate construction.

## 8. WANT, NEED and CAN are not synonyms

| Verb | Draft gloss | Contrast that must survive |
|---|---|---|
| `kong` | want | desire for an entity vs desire for an event |
| `tek` | need | desire vs necessity; unconditional vs goal-relative need |
| `fam` | can | ability vs permission vs event possibility |

Semantic exercises:
- A wants water; A needs water to achieve goal G.
- A wants to leave; A wants B to leave.
- A can leave; A actually leaves.
- A needs to leave; A is required to leave by an external rule.

These examples are English prompts for future Arcane constructions. No unapproved embedded-clause syntax is implied.

## 9. Acceptance criteria for a future surface grammar

A selected role system and verb-frame grammar should pass all of the following before learner-facing forms are treated as stable:

1. Participant reversal changes the interpretation in a predictable way.
2. Recipient and beneficiary remain distinct where both occur.
3. Source, goal, path and static location are not conflated.
4. Perception, inference and reported information remain distinct.
5. Direct quotation and reported proposition have recoverable boundaries.
6. Ability, permission and physical possibility are distinguished.
7. Desire and necessity are not treated as synonyms.
8. Attempted actions do not automatically entail completed outcomes.
9. Omitted arguments are allowed only under an explicit omission policy.
10. Unknown frames are reported unresolved rather than guessed from English.

## 10. Recommended next action

Do not expand the vocabulary to solve these gaps. The next productive step is a **role-encoding decision** for Vernacular: compare an invariant word-order strategy, explicit role marking, and a controlled hybrid against the reversal and omission tests already recorded in Phases 7M–7P. Then implement only the selected proposal in a small, clearly labelled teaching corpus and test its consistency.
