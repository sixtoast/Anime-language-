## Evidence policy

The v5 lexicon records Phase 5 vernacular items as PROPOSED. A gloss does not establish word order, argument roles, complement syntax or morphology. The formal pattern HEAD + ARGUMENTS + MODIFIERS must not automatically be treated as vernacular syntax. Phase 7F explicitly warns against inferring canonical SVO from the Phase 7E pilot.

Evidence labels:
- **Lexicon evidence:** the form and gloss occur in the draft lexicon.
- **Semantic prompt:** a meaning contrast a grammar should express.
- **Unresolved:** no supported Arcane surface construction is currently established.

## How to use this bank

The highest-impact gaps are participant-role recovery, three-argument verbs, embedded clauses, clause negation, question scope, source/goal/path marking and temporal attachment. Each prompt should later become a positive example, a minimal contrast, an ambiguous or malformed variant, and an expected interpretation or explicit unresolved outcome.

A sentence is **attested** only when an exact source example is recovered with version, register and source location. A **reconstruction** must separate evidence from inference. A **proposal** remains experimental and cannot prove the rule that generated it. Do not mark a parser test passed without running it and recording observed input/output.
