# Arcane Phase 7H — vernacular argument-marking alternatives

**Status:** Decision paper; no option approved as canon  
**Date:** 2026-10-15  
**Evidence:** canonical register distinction; Phase 5 proposed lexicon; Phase 7E pilot; Phase 7F frame note; Phase 7G contrast tests  
**Canon effect:** none

## 1. Decision to make

Arcane's proposed vernacular verbs need a reliable way to express participant roles. The available lexicon supplies words and glosses but does not establish a complete vernacular syntax. The formal rule `HEAD + ARGUMENTS + MODIFIERS` belongs to the formal layer and cannot automatically settle ordinary clause order.

This paper compares possible approaches without silently choosing one.

## 2. Requirements

Any selected system must:
- distinguish agent/experiencer, theme, recipient, source, goal, content and beneficiary where relevant;
- allow a listener to recover roles without relying on unstated assumptions;
- support two- and three-participant clauses;
- support embedded content, such as “A says that B helped C”;
- work with questions, negation, temporal modifiers and optional arguments;
- be learnable and reasonably concise in ordinary conversation;
- coexist with Technical, Formal and Performed registers;
- preserve older source-attested forms and permit version-aware compatibility;
- mark genuinely ambiguous input instead of choosing a convenient interpretation;
- avoid implying physical feasibility or causation merely from linguistic intent.

## 3. Option A — fixed constituent order

**Description:** grammatical roles are primarily inferred from a fixed order such as subject–verb–object.

**Strengths**
- Easy to learn and economical for short clauses.
- Does not require a large inventory of role particles.

**Risks**
- Three-participant verbs need extra rules for recipient and beneficiary.
- Fronted questions, topic marking and omitted arguments can obscure role order.
- If order is violated in expressive speech, ambiguity may rise.
- The proposed SVO pilot does not constitute source evidence.

**Tests required**
- reverse giver and recipient;
- add a beneficiary;
- front a question word;
- omit a recoverable object;
- embed a proposition;
- contrast topic-marked and unmarked clauses.

**Current status:** viable candidate, not established.

## 4. Option B — role particles or case markers

**Description:** overt markers identify roles independently of constituent order.

**Strengths**
- Can make participant roles explicit in flexible word order.
- Helps disambiguate three-participant verbs and embedded clauses.

**Risks**
- No complete source-backed role-marker inventory has been established in the inspected material.
- Coining markers now would add unsupported morphology.
- Markers require rules for attachment, scope, omission and combinations with existing particles.

**Tests required**
- one marker per role or a documented economical system;
- marker order and attachment;
- interaction with question and topic particles;
- ambiguity if a marker is missing or repeated;
- compatibility with clitics and performed register.

**Current status:** structurally attractive, but cannot be implemented without source recovery or explicit design approval.

## 5. Option C — adpositional phrases

**Description:** nouns are related through separate words such as prepositions or postpositions.

**Strengths**
- Potentially transparent for source, goal, recipient, beneficiary and path.
- Can be introduced incrementally.

**Risks**
- The current proposed `desh` entry means “in/at”; it must not be repurposed as “to” or “from”.
- The inspected lexicon does not establish a complete directional/role adposition set.
- Adposition scope around nested clauses and temporal phrases must be defined.

**Tests required**
- distinguish source, goal and path;
- distinguish recipient and beneficiary;
- test phrase attachment in embedded content;
- document adposition placement and omission.

**Current status:** viable only after the relevant forms and meanings are sourced or approved.

## 6. Option D — hybrid system

**Description:** use a default order for ordinary clauses and explicit markers or adpositions when role structure would otherwise be ambiguous.

**Strengths**
- Can keep common clauses concise while handling complex argument structures.
- Allows explicit disambiguation for GIVE, TEACH, SAY and motion verbs.
- Could preserve the proposed simple conversation pilot as an experiment without making its order universal.

**Risks**
- More complex to specify: the grammar must state exactly when marking is obligatory.
- Optional markers can create inconsistent usage unless the rules are clear.
- Still depends on source evidence or approval for each marker.

**Tests required**
- specify default order;
- specify mandatory marking environments;
- test optionality, omission and constituent movement;
- test the full Phase 7G contrast pack;
- define how parser diagnostics expose unresolved ambiguity.

**Current status:** promising design candidate, not selected.

## 7. Comparison matrix

| Criterion | A: fixed order | B: role markers | C: adpositions | D: hybrid |
|---|---|---|---|---|
| Short simple clauses | Strong | Moderate | Moderate | Strong |
| Three-participant verbs | Needs extra rule | Strong if complete | Strong if complete | Potentially strong |
| Flexible order | Weak | Potentially strong | Potentially strong | Moderate |
| Existing source evidence | Insufficient for vernacular order | Insufficient marker inventory | Incomplete inventory | Incomplete |
| Risk of invented grammar | High if promoted now | High if forms coined now | High if glosses expanded | High without explicit constraints |
| Ease of incremental learning | Strong | Moderate | Moderate | Moderate |
| Canon-ready today | No | No | No | No |

## 8. Recommendation

Do **not** approve any option as canon yet. The next evidence action should be to search the historical language materials for actual vernacular clauses, role markers, adpositions and three-argument verbs. Record exact examples and source locations. If that search finds no usable evidence, bring a narrowly scoped design decision to the project owner with example paradigms for all four options.

If an option is approved, it must be tested against the 28 Phase 7G cases before canonical promotion. The tests should be expanded only when a concrete failure exposes a missing requirement; avoid repeatedly rewriting the same proposal.
