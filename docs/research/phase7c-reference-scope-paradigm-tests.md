# Arcane Phase 7C — reference and scope paradigm test pack

**Status:** Provisional analysis and test design; not canon  
**Date:** 2026-10-15  
**Depends on:** `docs/research/phase7b-lexicon-strata-and-reference-scope-recovery.md`  
**Canon effect:** none

## 1. Objective

Turn the recovered performed-reference inventory into a testable paradigm, while preventing the audit notation from being mistaken for canonical spoken Arcane. This pack defines what must be checked and supplies explicitly provisional test representations. It does not claim to recover the missing v2.0 morphology rules.

## 3. Hypothesis to test

**HYPOTHESIS R-1 (provisional):** initial consonant maps to reference family (m = SELF, n = FIELD, r = TARGET); the remainder of the form distinguishes scope.

Evidence supporting the hypothesis is the repeated onset across the listed SELF, FIELD and TARGET forms. Limitations:
- the vowel-to-scope mapping is only partly regular across the recorded forms;
- TARGET includes additional forms for path, network and extended region;
- the v5 lexicon does not itself state the full phonological derivation or allowed combinations;
- formal forms MI/NI/RI and performed forms mi/ni/ri may differ in register or function beyond pronunciation.

**Decision:** retain as a testable hypothesis, not a productive canon rule.

## 6. Candidate disambiguation mechanisms

No mechanism is selected as canon by this document. The following alternatives should be tested against source examples and spoken usability.

### Option A — syntactic-slot disambiguation

A numeral parser and a reference-slot parser might admit different lexical classes. This is acceptable only if the grammar defines the slots and makes the parse unique.

**Risk:** if the same surface position can host both a numeral and a reference, the collision remains.

### Option B — explicit boundary or citation-form disambiguation

A boundary, full reference form, or separate citation form might distinguish the lexical items in formal/technical speech.

**Risk:** no such boundary or alternative form is established by the current evidence. Do not invent a marker and call it canon.

### Option C — register-restricted homophony

The collision may be tolerable if the numeral/unit forms and performed reference forms are confined to clearly separated registers or channels.

**Risk:** the v5 lexicon labels the reference fusions as Performed and the digits/units as Shared, which suggests register separation may help, but it does not prove contexts can never overlap.

### Option D — lexical redesign

One or more forms could be changed in a future approved version if contextual grammar cannot guarantee unique interpretation.

**Risk:** this would alter established forms and requires explicit change control, source review, and regression coverage. It is not the default choice.

## 7. Conversion and semantic invariants

Any future formal-to-performed conversion must preserve the reference and scope intended by the source expression. It must not:
- turn a target reference into a physical target acquisition;
- infer that specifying a target guarantees sensing or successful coupling;
- change a spatial scope into a different region type;
- treat a reference token as a magical operation;
- silently resolve a lexical collision using the intended effect as a guess.

The distinction between a reference (which identifies a role/entity) and a measurement (which requires a physical information pathway) remains mandatory.

## 8. Evidence needed to promote R-1

Before accepting a productive morphology rule, recover:
1. the original v2.0 explanation of reference + scope fusion;
2. the complete scope-vowel mapping, including the path/network/extended-region forms;
3. whether forms are built compositionally or memorised lexical fusions;
4. the boundary and stress behaviour in performed speech;
5. the attachment rules for `s-`, `sh-`, `f-`, `wi`, and `we`;
6. source-derived positive and negative examples;
7. a test proving every executable string has one parse.
