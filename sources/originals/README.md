# Original Source Files

Place original documents and files here when they are suitable for version control.

Examples include PDFs, text documents, spreadsheets, vocabulary lists, grammar specifications, magic-system notes, audit reports, and earlier versions.

## Handling rules

- Preserve the original filename and contents wherever practical.
- Do not overwrite an earlier version with a newer one; keep both and distinguish them by filename or subfolder.
- Add provenance details to the source inventory when known: original filename, source conversation or branch, approximate date, and whether the file is original or exported.
- Large or binary files may be better stored using Git LFS or another durable archive if repository limits become an issue.
- Do not upload secrets or private credentials.
