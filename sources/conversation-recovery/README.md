# Conversation Recovery Records

Use this folder for indexes and notes that help recover language-development material from earlier project conversations.

Record references to the relevant conversation or branch, the topic covered, the files known to have been created, and whether the original file has actually been recovered.

Distinguish direct quotations or exported source material from summaries and reconstructions. A conversation summary is useful context, but it is not a substitute for an unavailable original specification.

Track missing items explicitly so they can be retrieved later without guessing.
