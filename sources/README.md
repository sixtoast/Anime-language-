# Source Archive

This area holds source material used to recover and develop the Anime language and its magic system.

## Principles

- Preserve originals unchanged whenever possible.
- Record where a file came from, its original filename, and any known date or conversation/branch context.
- Do not silently promote historical or provisional material to canon.
- Keep extracted text, cleaned copies, summaries, and interpretations separate from the original files.
- Never commit passwords, API keys, access tokens, or other secrets.

## Folders

- `originals/` — original uploaded or recovered files.
- `conversation-recovery/` — indexes and notes about material recovered from earlier conversations.

If a source is referenced but unavailable, record it as missing rather than reconstructing it from memory.
